# 考勤判定在设备端完成，签到事件与考勤结论分离

签到事件（某人某时刻被识别到）是不可变事实，只增不改；考勤结论（正常／迟到／缺勤）是按课次规则算出的派生结果，可重算。课表与规则由云端下发并缓存到设备 NVS，**判定在设备端执行**。

## 决策理由

断网时设备仍需当场告诉学生"签到成功"还是"迟到"，因此判定不能只在云端。但规则会变、时间也可能不可信（板上无 RTC，断电后未联网时设备不知道准确时间），所以没有把结论与事件混为一条记录：设备在时间不可信时把事件标为 `time_trusted=false` 并附课次与运行时刻，联网后补发时间校准事件，由后端重算映射。教师把"缺勤"改判为"请假"也走同一条路——只重算结论，事件不动。

## 后果

- 规则实现存在两份（设备端执行、后端复算），必须用同一组用例交叉验证一致性。
- 事件存储需带幂等键（设备 ID + 事件序号 + 时间戳），否则补传会产生重复。
- 迟到阈值必须能吸收设备时钟漂移，因此设下限 5 分钟。
