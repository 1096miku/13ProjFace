# 人脸比对在设备本地完成，不把照片上传服务器

人脸检测与 1:N 比对全部在 ESP32-S3 上离线执行，照片不出设备。社区常见做法（如 Seeed 的 `face_rec_api`）是设备只抓拍、把照片 POST 到树莓派/PC 上用 InsightFace 比对，本项目**不采用**该路线。

## 决策理由

"上传服务器比对"是产品选择而非技术必需——ESP32-S3 在 ESP-IDF 5.5.x 上是官方支持的人脸识别目标（检测约 37–40 ms/帧、识别约 255 ms/帧，模型 1.42 MiB，特征 2050 B/人）。选本地方案是为了保住"离线可用"这条核心卖点，并避免人脸照片离开设备带来的隐私问题。代价是识别精度明显低于服务端大模型方案，且受摄像头能力限制（GC0308 不支持自动曝光/白平衡控制、无自动对焦）。

## 后果

- 识别准确率指标按"演示级"设定（50 人库 TOP-1 ≥ 90%），不得宣传为身份认证级能力。
- 不实现活体检测，照片可代签，必须在文档中作为已知限制写明。
- 若后续精度不足，切换到服务端比对的成本主要在固件侧的网络与配网逻辑，业务与领域模型不受影响。
