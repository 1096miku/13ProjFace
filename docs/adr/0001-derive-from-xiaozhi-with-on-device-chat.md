# 从 xiaozhi-esp32 派生，并在设备端保留自由对话

本项目基于 xiaozhi-esp32 v2.2.4 派生（设备端固件），在同一颗 ESP32-S3 上同时承载考勤业务与语音助手。原因是项目要求"必须使用 ESP32 + 小智AI"，而本开发板的板型支持（`main/boards/esp32s3`，自定义 ESP32-S3 开发板）在 xiaozhi 中已经就绪；备选方案是从 `11_PCA9577` 派生（LVGL 与硬件链路同样已跑通，但需从零实现语音对话）。

## 后果

- **ASR/LLM/TTS 在服务端**（官方 xiaozhi.me 或自建 `xiaozhi-esp32-server`），因此**断网时自由对话必然不可用**，而考勤判定、屏幕与内置提示音必须继续工作。这是本项目"断网可用"的准确含义。
- app 分区只有 4.13 MB，`xiaozhi.bin` 已占 2.86 MB，**人脸模型不能编进 app**，必须走独立 flash 分区加载。
- 摄像头与人脸识别必须与语音链路**分时复用**：待机时关闭摄像头、挂起识别任务，避免与唤醒词/音频链路争抢 PSRAM 与 CPU（该组合已有公开的缺陷记录）。
- 固件不跟随上游自动升级：板型标识唯一化为 `VEHICLE-ESP32S3-TERM` 并关闭自动升级，否则自定义固件会被官方标准固件覆盖。
